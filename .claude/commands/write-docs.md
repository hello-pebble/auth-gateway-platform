# Skill: 시나리오 문서 작성

이 스킬이 활성화되면 아래 규칙에 따라 문서를 작성한다.
이 프로젝트의 목표는 작성자의 사고력과 문제해결능력을 보여주는것이며, 모든 문서는 가독성을 최우선으로 한다.

## 목표
문제 -> 해결 -> 결과 -> 도메인(기능) 을 이력서로 한문장 담을 수 있도록 할 수 있는 근거 시나리오 작성하기.

## 예시
교육 커뮤니티 서비스를 개발하였습니다.
기능 중에 게시글 리스트 조회하는 기능이 있는거예요.
근데 문제가 있는거죠. 
트래픽이 조금 있다보니 DB I/O문제가 있는거예요.
어떻게 해결할까요?
이 느린 응답문제를 로컬캐시 도입으로 그 결과 350ms -> 20ms 로 개선이 된거예요.

## 결과
리뷰 게시글 조회시, 느린 응답문제 발생 및 로컬 캐시 적용으로 평균 응답속도 350ms -> 20ms 개선.

## 에이전트 도입
문제 발생 확인
방법 제안
사용자 응답 반영
