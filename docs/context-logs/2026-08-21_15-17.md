# 2026-08-21 15:17 — README mermaid 다이어그램 가독성 수정

## 작업 내용

`README.md`의 mermaid 다이어그램 렌더링/가독성 문제 수정.

### 1. 08번 RTR 다이어그램 대비 문제
- 원인: `subgraph Before/After`에 `fill:#1e293b,color:#f1f5f9` 지정. mermaid에서 subgraph의 `color`는 하위 노드에 상속되지 않아 어두운 배경 위에 기본(검은) 글씨가 됨.
- 조치: subgraph style 제거, 노드별 색상 지정 (`B2`/`A5` 빨강, `A2` 파랑, `A4` 초록).

### 2. `[/oauth2/jwks\n공개키]` 파싱 깨짐 (07번, 13번)
- 원인: mermaid에서 `[/`는 평행사변형 노드 시작 토큰. `/]`로 닫지 않아 파싱 실패.
- 조치: `["/oauth2/jwks<br/>공개키"]`로 인용부호 감싸기.

### 3. `\n` 줄바꿈 전체 치환 (14곳)
- 원인: GitHub이 쓰는 mermaid 10.x는 라벨 내 `\n`을 줄바꿈이 아닌 리터럴 문자로 렌더링.
- 조치: 모든 노드 라벨 `\n` → `<br/>`, 라벨을 `"..."`로 인용.
- 대상 섹션: 02, 03, 07, 09, 10, 13.

## 결정 사항
- 3번은 사용자가 지목한 8번 외 전체 파일로 확장 적용. 같은 원인 계열이고 diff가 작아 한 번에 처리.

## 미완료 / 후속
- 실제 렌더링 검증 미완료. 이 세션의 Bash 도구가 샌드박스라 파일 쓰기가 반영되지 않아 로컬 스크립트 검증 불가. GitHub 푸시 또는 에디터 미리보기로 확인 필요.
