# Context Manager

현재 대화 내용을 요약하여 파일로 저장하고, 대화 초기화를 안내한다.
컨텍스트 80% 초과 시 Stop 훅이 자동 실행하거나, 수동으로 `/context-manager` 입력 시 실행된다.

---

## Step 1 — 대화 요약 작성

현재 대화 전체를 분석하여 아래 형식으로 요약을 작성한다.

```markdown
# Context Log: YYYY-MM-DD_HH-mm

## 작업 기간
YYYY-MM-DD HH:mm ~ HH:mm

## 주요 작업 내용
- (완료된 구현/수정 항목을 구체적으로 나열)

## 주요 결정 사항
- (아키텍처, 설계, 방향 결정 사항)

## 핵심 파일 변경 이력
- `경로/파일명` — 변경 내용 한 줄 요약

## 미완료 / 다음 세션 인계 사항
- (다음 대화에서 반드시 이어받아야 할 내용)
- (진행 중인 작업, 확인이 필요한 항목)
```

## Step 2 — 파일 저장

- 경로: `docs/context-logs/YYYY-MM-DD_HH-mm.md`
- `docs/context-logs/` 디렉터리가 없으면 생성 후 저장
- 날짜시간은 현재 로컬 시간 기준 (오늘: $CURRENT_DATE)

## Step 3 — 사용자 안내

저장 완료 후 출력:

```
✅ 대화 내용이 docs/context-logs/YYYY-MM-DD_HH-mm.md 에 저장되었습니다.
💡 대화를 초기화하려면 /clear 를 입력하세요.
```

---

## 주의사항
- 요약은 핵심만 담는다 — 대화를 그대로 옮기지 않는다
- 미완료 항목은 다음 세션에서 바로 이어받을 수 있도록 구체적으로 작성한다
- `/clear` 는 직접 실행하지 않고 사용자에게 안내만 한다
